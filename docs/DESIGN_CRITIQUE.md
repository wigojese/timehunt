# Design critique (living)

Scores in this project are subjective. Nothing here is user-tested.

## Stage 0 self-critique
1. The STRATA work is the strongest asset and the least proven. It is drawings. No gesture, scroll or zoom has been built.
2. My earlier simulation misled. The correction is in `STAGE_0_AUDIT.md` section 4.
3. The gray-box proves a rules idea, not fun. The first real test is whether ten cases and eight shared Insight produce interesting decisions.

Earlier critiques are in `source-documents/`.

## Stage 1 self-critique
1. The competitor read is shallow: start screens, FAQs and secondary coverage, no full sessions.
2. The most useful result is arithmetic, not research: free dossiers carry about 95% of the information, so Insight allocation is a small lever (D-013). It is a model and has not met a real pack.
3. Personas are invented. Treat them as thinking aids, not evidence.

## Stage 2 self-critique
| Lens | Rating (subjective) | Evidence |

| Gameplay integrity | 6/10 | Exact solver, 23 tests, no exploit found in the model. But the model has no reasoning skill. |
| Behavioral pleasure | 3/10 | Entirely untested. Allocation is a small lever in the model. |
| Historical credibility | n/a | No historical claims added. |
| Accessibility | n/a | Not in scope. |
| Technical health | 7/10 | Rules are testable apart from any UI. A reference model exists. |

**Three weakest points.**
1. Chance-only play (M7). The most important question, whether Insight allocation is interesting, is exactly what the model cannot answer.
2. Clue menus and windows are assumed. The numbers will move with real content.
3. I recommend removing Trace on model evidence alone. It is the user's named verb and the model may be missing a reason players want it.

## Stage 3 review book
Plan: bone and oxide tokens from STRATA, Young Serif and Sofia Sans, left-aligned single column. One memorable element: the day as a core sample (layers by answer year, region colour bar, verification box, gap arithmetic) and a per-case strip showing which clue cuts which year. Rejected defaults: tracked caps eyebrows, identical cards, gradient hero numbers. Checked at 1100px and 390px, no horizontal scroll. Known weakness: the region colour is a weak encoding (several cases span regions).

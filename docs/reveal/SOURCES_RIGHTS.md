# Sources and rights manifest, World Reveal prototype

**Draft.** Nothing here has been cleared by a person. The agent verified facts only from pages it opened (V1 or V2), recorded below.

## Media

The prototype contains **no third-party image, audio, video, scan or archival facsimile.** Every graphic is an original drawing generated in code from the sourced data: the stone diagram (band height proportional to line count), the chart of regions, the route schematic (no coastline), the calendar cells, the lanes. Each drawing says on screen that it is a diagram. Fonts (Young Serif, Sofia Sans, Sofia Sans Extra Condensed) are SIL Open Font License 1.1 and load from Google Fonts in the prototype; a shipped app must self-host them with the licence text (Q-17).

## Text

All prose is original wording. Facts are paraphrased from the sources below; no passage is quoted at length. Wikipedia text is CC BY-SA 4.0: if any wording is ever reused rather than paraphrased, attribution and share-alike apply. WHO and CDC pages are cited for facts and figures only.

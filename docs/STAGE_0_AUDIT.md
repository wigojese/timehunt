4. The free dossier: contents and the residual-candidate target (Q-04).
5. The scoring formula and how assisted and missed cases are shown (Q-05).
6. Sequential cases or skip and return (Q-06).
7. Dating precision and the per-clue convention (Q-07, Q-08).

## 11. What I got wrong earlier in this project

Recorded so the next session does not repeat it.

1. I called a simulation "no history at all" while it contained a free opening card, and recommended Trace 3 / Insight 8 / 2 Locks on that basis. Do not use that recommendation.
2. My STRATA 1.5 satellite clue used a 1 January rule. The default should be end-of-year.
3. I claimed 13 px text floors in the 1.5 boards; six labels are 12.5 px.
4. I described the STRATA 1.5 motion board as proof of a camera model. It is drawn frames only.
5. The first STRATA board's contrast table showed the tokens pass, but that says nothing about rendered text over textures.
